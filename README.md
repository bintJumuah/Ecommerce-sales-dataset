# Ecommerce-sales-dataset (Interactive Dashboard creation using MS Excel
## Project Objective
Ecommerce wants to create an annual sales report for 2023/2024

## Dataset used
https://github.com/bintJumuah/Ecommerce-sales-dataset/blob/main/08%20E-Commerce%20Orders.xlsx

## Questions (KPI)
* What is the total revenue?
* What is the total profit?
* What is the total quantity sold?
* What is the total number of orders?
* What are the total sales by region?
* What is the total profit by category?
* What are the total sales by product?
* Which product has the highest sales?
* Which category generates the highest profit?
* Which region has the highest sales?

Dashboard Interactive https://github.com/bintJumuah/Ecommerce-sales-dataset/blob/main/08%20E-Commerce%20Orders.xlsx

## process
* Clean data for missing values and additions colomn.
* make sure data is consistent and clean.
* create Pivot table according to the question asked.
* Merge all Pivot Tables into on dashboard and apply slicer and KPI to make dynamic.
